## ⚙️ How It Works

The application functions as a static web page. The `index.html` file serves as the entry point, rendering the structure and semantic elements of the blog layout, while the linked `css/style.css` file dictates the visual appearance and responsive behavior.

## ♿ Accessibility

Given the project's focus, accessibility is a primary consideration:

* Uses semantic HTML tags to ensure screen readers can accurately interpret page structure.
* Contains a dedicated privacy policy document (`docs/Tech_Blog_App_Privacy_Policy.txt`).
